# PDF編集ソフト

出版・印刷の仕事で使いやすい、日本語対応のPDF編集ソフトを目指しています。

PDFへの赤字入れから、印刷前のチェック、ページの編集、配信用データの作成まで、制作に必要な作業をまとめて行えることが目標です。

> **開発目標:** 以下は今後実現したい機能です。すべての機能が現在利用できることを示すものではありません。

## このソフトでできるようにしたいこと

1. PDFに修正指示を書き込み、関係者と校正する
2. ページを編集し、複数のPDFをまとめたり分けたりする
3. 印刷に適したPDFかどうかを確認する
4. 日本語の縦書きやルビを含む文書を扱う
5. 電子配信や共有に使えるPDFを作る

## 機能一覧

### 1. PDFに赤字を入れて校正する

編集者・著者・校正者が、PDF上で修正内容を確認・共有できるようにします。

- 文字の削除（取り消し線）、挿入、置き換えの指示や、付箋コメントを追加
- JIS校正記号に近い記号を使って修正を指示
- 注釈を一覧にし、CSVまたはPDFに書き出し
- 複数の人が入れた注釈を一つのPDFにまとめる
- 初校・再校など、異なる版の変更箇所を自動で比較

### 2. ページを編集する

- ページの挿入、削除、差し替え、回転、並べ替え
- ページ番号（ノンブル）や柱（ページ上部などに入れる書名・章名）の追加
- 複数のPDFの結合・分割と、台割に沿った管理
- ほかの方法で直せない場合に限り、文字の軽微な修正や画像の差し替え

### 3. 印刷前にPDFをチェックする

印刷所へ入稿する前に、設定やデータの不備を見つけられるようにします。

- PDF/X-1a・PDF/X-4形式での書き出しと規格チェック
- フォントの埋め込み漏れ、解像度の低い画像、RGBカラーの混在を検出
- トンボ（仕上がり位置の目印）や塗り足しの不足を検出
- CMYK・特色ごとの色の確認と、総インキ量（TAC）のチェック
- オーバープリント（色を重ねて印刷する設定）のプレビューで、スミノセ・白ノセを確認
- TrimBox（仕上がり範囲）・BleedBox（塗り足し範囲）の確認と設定

### 4. 日本語の組版を確認する

- 縦書きでも、文字選択や注釈が正しく動作
- OpenTypeフォントや合成フォントなど、和文フォントの表示と埋め込みを確認
- ルビや外字が正しく表示されているか確認

### 5. 電子配信の準備をする

- しおり（目次）やリンクを作成
- タグ付きPDFに対応し、読み上げなどのアクセシビリティを向上
- Webで配布しやすいようにファイルサイズを最適化
- EPUBなどへの変換、または変換ツールとの連携

### 6. セキュリティと権利を管理する

- パスワードを設定し、印刷・コピーなどを制限
- 墨消しで個人情報や未公開情報をPDFから完全に削除
- 「見本」「校正用」などの透かしを追加
- 契約や責了確認に使う電子署名に対応

### 7. 作業を効率化し、ほかのツールと連携する

- 複数ファイルの変換・チェックをまとめて行うバッチ処理（アクション）
- 外部の著者やデザイナーとPDFを共有するクラウド共同校正
- InDesignなどのDTPソフトと連携
- OCR（画像内の文字を読み取る機能）で、紙資料や既刊本をデジタル化

## 使い方

`index.html` をブラウザ（Chrome / Edge / Safari / Firefox の最新版）で開くだけで使えます。インストールやサーバーは不要です。

- PDFの処理はすべてブラウザ内で行われ、ファイルが外部に送信されることはありません。
- ライブラリ（pdf.js / pdf-lib、文字の読み取りを使うときは tesseract.js と辞書データ）はCDNから読み込みます。社内サーバーに置く場合は `js/core/config.js` の `CFG` と、`index.html` の `<script src>` のURLを変更してください。

### 開発時の注意

- JSファイルは `<script>` で順番に読み込まれ、関数や変数をファイル間で共有しています（モジュールではありません）。そのため `index.html` での**読み込み順が重要**です。新しいファイルは、それを使うファイルより前に追加してください。
- 読み込み時にすぐ実行されるコード（`on('#btn','click',関数名)` など）は、参照する関数が同じファイルか、それより前のファイルで定義されている必要があります。クリック時などに呼ばれる関数は、どのファイルにあっても構いません。
- 新しい機能は、上の分類に沿ったフォルダに追加します（例: 校正の機能は `js/proof/`、入稿チェックは `js/press/`）。
- `index.html` はファイルを直接開いても動きますが、ローカルサーバーで確認することもできます。

```bash
python -m http.server 8765
```
